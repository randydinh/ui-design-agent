# UI Design Agent brief

Goal: a standalone public GitHub repository that Temari can install from its URL as an external UI-design specialist on a compatible Codex host.

One coordinator combines Interface Design (visual system and interaction), UI UX Pro Max (research and usability), and Impeccable (critique and refinement). Use native workers when available, with inherited models and a serial fallback. Existing product truth, user brief, and supplied design system remain authoritative.

Ship a self-contained Codex plugin marketplace, pinned upstream payloads and licenses, deterministic package verification, Git URL installation instructions, and a representative design-review evaluation. Temari remains responsible for workflow admission and acceptance; the specialist does not replace engineering verification .

Accept when a fresh host installation from the published Git URL exposes the UI Design skill and all three intact upstream resources, the search tool runs without global skill dependencies, package validation passes, and independent review finds no material contract gaps.

Do not ship credentials, private application source, customer data, implicit runtime downloads/hooks, or claim that Figma frames prove runtime accessibility or charger telemetry.

Additional requirement: host-global discovery in new Temari chats and appropriate SME workflow routing. Prove host inventory exposure separately from actual selection/delegation. A small Temari conversational-entry integration is planned; protected workers and canonical acceptance remain unchanged.
